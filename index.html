🐰 Crecimiento de Población

📌 Contexto del Problema Real

En condiciones biológicas controladas, colonias de bacterias, insectos o conejos incrementan su tamaño de forma proporcional a las generaciones anteriores, permitiendo predecir el ritmo reproductivo ideal.

⚙️ Explicación del Algoritmo

El simulador calcula la cantidad total de parejas combinando las generaciones previas paso a paso:

1. Punto de partida: Comenzamos el primer mes con una pareja joven y el segundo mes con esa misma pareja ya madura lista para reproducirse.

2. Ciclo mensual: A partir del tercer mes, el programa inicia un conteo repetitivo donde la población actual siempre es el resultado de sumar las poblaciones de los dos meses anteriores.

3. Resultado final: El ciclo se detiene automáticamente al llegar al mes ingresado por el usuario, mostrando cuántas parejas totales existen bajo este modelo natural.

🔐 Validación de Contraseñas

📌 Contexto del Problema Real

La seguridad informática y criptografía digital protegen claves y datos mediante propiedades matemáticas exclusivas de números primos, garantizando que las claves sean inmunes a hackeos directos.

⚙️ Explicación del Algoritmo

El sistema pone a prueba el número ingresado para verificar si es un "bloque numérico indestructible" (un número primo):

1. Regla base: El número 1 se descarta de inmediato porque la seguridad criptográfica requiere valores mayores.

2. Prueba de división: El programa realiza un recorrido automático intentando dividir tu número por cada uno de los números intermedios (empezando desde el 2 hasta llegar justo antes de tu número).

3. Veredicto instantáneo: Si alguna división da un residuo de cero, significa que el número "se rompió" (es compuesto y se mostrara que no es primo) y la clave es vulnerable. Si el ciclo termina y nadie pudo dividirlo exactamente, se aprueba como una clave segura y que es primo.

💰 Plan de Ahorro Progresivo

📌 Contexto del Problema Real

Para construir hábitos financieros sólidos y dinámicos, una persona incrementa progresivamente sus depósitos mensuales guiándose por la serie lógica, potenciando la acumulación final de capital.

⚙️ Explicación del Algoritmo

El programa calcula cuánto dinero logras guardar al usar una alcancía que te exige un esfuerzo cada vez mayor:

1. Depósito variable: En vez de ahorrar siempre lo mismo, el sistema calcula el monto de cada mes sumando lo que depositaste en los dos meses anteriores.

2. La caja fuerte: Al mismo tiempo que calcula el depósito del mes, el algoritmo lo va sumando de inmediato dentro de una variable "acumuladora" (como una alcancía real donde el dinero se junta).

3. Balance total: Al finalizar la cantidad de meses que elegiste, el sistema te muestra la suma total de todo el dinero que se fue acumulando periodo tras periodo.
